## 🌌 遊戲簡介
《星體融合 (Cosmic Merge)》是一款以真實天體物理、天體軌道美學與解壓音效設計為核心的 2D 物理合成益智遊戲。玩家在重力艙中調度並投擲各階天體，引發天體間的引力融合，從微型小行星一路演化至太陽與終極黑洞奇異點！

---

## ✨ v1.2.0 重大更新亮點

### 1. 視覺反饋與特效大升級 (Juice & Visuals)
- **多層天體柔光大氣層 (Atmospheric Glow)**：為全部天體建立內外雙層大氣散射光暈，太陽與黑洞具備動態呼吸脈衝。
- **土星環動態立體升級**：加入球體在光環背後的傾斜陰影投影、光環在前方的暗影帶，以及 8 顆沿著橢圓軌道旋轉的精細冰晶自轉微粒。
- **超新星爆發 (Supernova Merge)**：高等級天體（木星、太陽、終極黑洞）合成時引發全螢幕漫射星塵爆裂、高光閃爍與雙層環形震盪衝擊波。
- **深空動態背景**：深空加入 3 個緩慢隨機自轉的遙遠星雲（獵戶紫、仙女藍、翠青）以及定時划過夜空的微型流星拖尾。

### 2. 深度機制與玩法擴展 (Gameplay)
- **終極黑洞·奇異點 (Black Hole Singularity)**：太陽之上誕生終極黑洞！黑洞誕生瞬間引發超新星全屏爆裂，並一口吞噬周圍 2 顆微型隕石，獎勵海量連鎖積分；平時具備強大周邊引力井。
- **連鎖共鳴 (Cascade Chain) 機制**：連續在 2 秒內觸發 2 次以上融合時，倍率逐級提升 (1.5x, 2.0x, 2.5x, 3.0x...)，伴隨空靈水晶和弦琶音。
- **微重力輔助投擲儀**：發射磁軌加入真實重力落點拋物線弧度預覽與落點全息虛擬投影圈，支援拖曳微慣性物理模擬。

### 3. 邊界防禦與體驗修復 (Fixes)
- **頂部警戒線判定重構**：徹底消除彈跳擦邊誤判！改為天體在警戒線上「靜止停留超過 2.8 秒」才判定坍縮結束。
- **防死鎖推擠微衝量**：加入左右側壁與天體深層卡死推擠微衝量，避免天體在狹縫中死鎖。

## 🛠️ 技術架構
- **渲染層**：HTML5 Canvas 2D + 視差動態星空 + 多層光暈與全息投影
- **物理引擎**：Matter.js 2D 剛體物理 + 引力井模擬 + 防死鎖推擠
- **音訊引擎**：Web Audio API 零外部資源純程式化合成音效與水晶和弦琶音
- **平台接入**：Playroom SDK 標準整合 (`startRun`, `finishRun`)
